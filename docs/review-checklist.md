# Review Checklist

Use this before accepting a small GuildMasters patch.

- Confirm recruitment, contract selection, timers, rewards, and persistence still work.
- Verify guild-level and reputation gates show the same requirements they enforce.
- Check contract cards and menus at narrow mobile widths.
- Avoid changing progression values unless the patch explicitly targets balance.
- Keep browser code dependency-free unless a dependency is clearly justified.
- Run the existing smoke/check commands after runtime changes.

Favor visible clarity and deterministic progression over hidden behavior.
