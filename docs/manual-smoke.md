# Manual Smoke Pass

Use this after a small GuildMasters UI or flow patch.

1. Load the guild screen and confirm stats render without errors.
2. Recruit or inspect an available member flow.
3. Open the contract list and verify locked requirements are visible.
4. Start an eligible contract and confirm its timer/state advances normally.
5. Complete or resolve one contract path and verify rewards/reputation display correctly.
6. Reload once and confirm guild progression persists.
7. Check the primary menus at a narrow mobile width.

Use the automated smoke/check commands as well when runtime logic changes.
